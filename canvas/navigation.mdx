Moving around the canvas works like any infinite canvas. You pan to reposition, zoom to change scale, and select nodes to work on them. Once these motions feel natural, the rest of **Canvas** gets out of your way.

## Move, zoom, and select

Pick the input you're using. The gestures map to what you'd expect from any modern canvas tool.

<Tabs>
  <Tab title="Mouse">
    - Left-click to select a node and interact with it.
    - Right-click anywhere to open the context menu.
    - Drag or scroll on empty canvas to pan around.
    - Drag a box on empty canvas to multi-select several nodes at once.
  </Tab>
  <Tab title="Trackpad">
    - Two-finger scroll to pan in any direction.
    - Pinch to zoom in and out.
  </Tab>
  <Tab title="Keyboard">
    | Action | Shortcut |
    | --- | --- |
    | Zoom in / out | `Cmd/Ctrl + scroll` |
    | Delete selected | `Delete` or `Backspace` |
    | Copy | `Cmd/Ctrl + C` |
    | Paste | `Cmd/Ctrl + V` |
    | Run / generate selected | `Enter` |
  </Tab>
</Tabs>

<Tip>
  Select a node and press `Enter` to generate without leaving the keyboard. It's the fastest way to run a node you've just set up.
</Tip>

<Note>
  Exact shortcuts may vary slightly across platforms and updates. You can always confirm the current keys in the in-app help.
</Note>
