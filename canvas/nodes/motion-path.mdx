Instead of describing camera moves in words, draw them. Motion paths let you sketch camera and subject trajectories over a connected image, and the Video node uses the drawing to direct the generated clip.

## Draw a motion path

<Steps>
  <Step title="Connect an image to a Video node">
    Motion paths work with the Video node's **Default** engine and need at least one connected image to draw on.
  </Step>
  <Step title="Open the editor">
    In the Video node's settings, find the **Motion path** section and choose **Draw motion path**. With one image connected it opens directly; with several, pick which image to annotate.
  </Step>
  <Step title="Draw your paths">
    The full-screen editor opens over the image. Draw in **red** for the camera path — it reads as cinematography, so a red line becomes a dolly, orbit, push-in, or FPV move. Draw in the other colors for **subject motion** — the things in frame that should travel along your lines.
  </Step>
  <Step title="Generate">
    Close the editor and run the node. The clip follows the motion you drew.
  </Step>
</Steps>

## Editor tools

| Tool | What it does |
| --- | --- |
| Select / move | Drag a path to reposition it |
| Pen | Draw a new path |
| Start marker | Click a path end to make it the start |
| Waypoint | Click along a path to add a timing point |
| Eraser | Remove a whole stroke |

You can draw up to 8 paths per image, with one camera path among them.

## Waypoints and timing

Waypoints pin moments to positions: add up to 12 along a path, and optionally give each a time in seconds. Times run in order and stay within the clip duration — if your last waypoint lands at 9 seconds, make sure the clip is at least that long. The node warns you when the timing and duration disagree, and when the underlying image has changed since you drew.

## How it steers the generation

Flowy composites your drawing onto the image and passes the annotated frame to the engine as a reference — the same reference slots described on the [Video node](/canvas/nodes/video) page, so an active motion path uses one of the 9 image inputs, leaving 8 for other references. Back in the node's Motion path section you'll find a summary of your paths, a motion preview describing the move in plain language, and **Edit** and **Remove** actions.

<Tip>
  Keep paths simple and intentional: one clear camera line plus one or two subject lines directs a shot far better than a scribble. You can always edit the drawing and regenerate.
</Tip>
