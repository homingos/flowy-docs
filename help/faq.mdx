Here are quick answers to the questions people ask most about Flowy. If you need more depth, follow the links into the rest of the docs.

<AccordionGroup>
  <Accordion title="What is Flowy?">
    Flowy is an AI creative-generation platform built around a multi-modal infinite **Canvas** and a **Studio** timeline editor. You move from prompt to pixel, frame to film, and idea to outcome in one connected space. New to it? Start with [concepts](/getting-started/concepts).
  </Accordion>

  <Accordion title="Do I need to install anything?">
    No. Flowy runs in your browser as a SaaS web app. There is no self-hosting and no offline mode.
  </Accordion>

  <Accordion title="What can I generate?">
    You can generate text, images, video, audio, storyboards, and interactive **Flam** experiences. 3D model generation is coming soon. See the [generators overview](/generators/overview) for details.
  </Accordion>

  <Accordion title="Which AI models power Flowy?">
    Chat runs on Claude, OpenAI, or Gemini, and you choose the backend. Images use Google Gemini, video uses Google Veo, and speech uses Gemini and ElevenLabs.
  </Accordion>

  <Accordion title="How do credits work?">
    Flowy uses a credit wallet, and generating consumes credits. New accounts start with free credits to explore. For the full lifecycle and how to top up, see [credits](/billing/credits).
  </Accordion>

  <Accordion title="What happens if a generation fails?">
    Credits are reserved when a generation starts and deducted only on success. If a generation fails, those credits are refunded automatically.
  </Accordion>

  <Accordion title="Can I work with my team?">
    Yes. You collaborate inside workspaces with **Owner**, **Editor**, and **Viewer** roles, plus live presence, multiplayer cursors, and comments. Learn more in [workspaces](/collaboration/workspaces).
  </Accordion>

  <Accordion title="Is there a mobile app?">
    Flowy works best in modern desktop browsers. The **Canvas** and **Studio** are not optimized for small mobile screens.
  </Accordion>
</AccordionGroup>
