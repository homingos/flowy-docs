Most issues in Flowy clear up with a retry or a refresh. Work through the section that matches what you're seeing.

## A generation failed or is stuck

You're never charged for failures — reserved credits refund automatically, so retrying is free.

<Steps>
  <Step title="Give it time">
    Video is the slowest node type. Let it run before assuming it's stuck.
  </Step>
  <Step title="Retry the node">
    Run it again — most failures are temporary.
  </Step>
  <Step title="Simplify your prompt">
    A shorter, clearer prompt often succeeds where a long one stalls. More tips in [generation help](/help/generating).
  </Step>
  <Step title="Check your balance">
    Generations need available credits to start. Check the wallet in [Settings → Billing](/billing/credits).
  </Step>
</Steps>

## An export or render is slow or failing

Renders take real time — longer compositions and higher resolutions take the longest. Keep the project open while a render runs; closing it can interrupt the export. If a render fails, retry it, and see the [export guide](/studio/export) for settings that affect render time.

## I can't edit a project

If the canvas is locked for you, you have the **Viewer** role, which is view-only. Request access and the owner can approve you as an Editor. See [sharing & access help](/help/collaboration) for the common access problems and fixes.

## My changes aren't syncing

Flowy syncs the canvas in real time for everyone in the project. If something looks out of date, refresh the page, check your internet connection, and confirm your teammates see the same state.

## I'm out of credits

Generating spends credits from the workspace wallet. Top up from **Settings → Billing** (from $5), or turn on auto-reload so it never happens mid-project. See [how credits work](/billing/credits).

## The canvas feels slow

Very large canvases with many nodes can lag. Group nodes to keep the canvas organized, close other heavy browser tabs, and make sure your browser is up to date.

## Browser support

Flowy runs best in modern desktop browsers. The Canvas and Studio aren't optimized for small mobile screens, so switch to a desktop if things look cramped or unresponsive on a phone.

## Still stuck?

Check the [FAQ](/help/faq) for quick answers, or [contact support](/help/contact) with the project name and any error text — we'll take it from there.
