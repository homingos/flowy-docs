---
title: "Update a brand kit"
description: "Partially update a brand kit's fields by id."
openapi: "/api-reference/openapi.json PATCH /v1/brandkits/{id}"
---

Send only the fields you want to change (brand, description, colors, fonts, keywords, …) — everything else is left as-is. Fetch the current values with [Get a brand kit](/api/get-brandkit) first if you need them.
